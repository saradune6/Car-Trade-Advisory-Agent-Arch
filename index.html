MCP Tool Calls
④ MCP TOOL SERVER — Model Context Protocol · standardized interface · swap mock ↔ real without touching agent logic
ulip_vehicle_lookup(reg_no)
Calls ULIP/Vahan API (Govt vehicle registry). Returns make, model, year, fuel type, insurance status, challan records, 200-pt inspection score.
→ ULIP / Vahan API
snowflake_market_data(model, city)
Queries Snowflake for current market prices, demand trend YoY, days-to-sell, price band. Powers depreciation forecast to 2030.
→ Snowflake MARKET_DATA
snowflake_service_history(reg_no)
Fetches service records from Snowflake. Service intervals, maintenance gaps, odometer history. Feeds LLM reasoning node.
→ Snowflake SERVICE_HIST
snowflake_car_catalog(budget, segment)
Queries upgrade car catalog filtered by budget and segment. Returns top 3 options with price, specs, platform support, EMI.
→ Snowflake CAR_CATALOG
MCP Advantage: Agent nodes call mcp_tool("name", args) — MCP layer handles auth, retries, error handling, mock↔real switching, and logging. Zero changes to agent logic when swapping data sources.
